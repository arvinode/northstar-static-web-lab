Frequently asked questions

Before we get started.

Native HTML disclosure elements provide a simple interaction without a framework.

Is this a real agency website?

No. Northstar Studio is fictional. The site is designed for learning and server testing only.

Does the static website submit form data?

No forms are included in this static project. The contact page contains informational content and links only.

Can I replace the font globally?

Yes. Update the central configuration and CSS variables described in the README to change the site-wide typography.

Can I use this with Apache and Nginx?

Yes. The files are static and can be served by either server. Use the matching configuration examples included in the repository.

Where should I put large files?

Place your own test assets in assets/media and link to them from media.html. Keep large binaries out of Git unless you intentionally want them versioned.

Server lab checklist

Things to inspect in the browser and on the VPS.

Browser

  • Network waterfall and initiators
  • Cache hit versus miss
  • Font swaps and layout shift
  • Image lazy loading
  • JavaScript console warnings

HTTP

  • Status and redirect chain
  • Content-Type and Content-Length
  • Cache-Control and ETag
  • Compression negotiation
  • Range requests for media

Linux server

  • Access and error logs
  • Worker/process utilization
  • Disk and network throughput
  • Permissions and ownership
  • Concurrent request behavior
